## 1. Summary of Changes

### A. Interactive Parameter Hover Guide Popups in `Abu Clock` PC Studio (`apps/abu-clock-gui/src-tauri/src/ui_html.rs`)
- Added a floating glassmorphic hover tooltip card (`#param-tooltip`) with smart viewport edge-clamping, plus a header toggle button (`HOVER GUIDE: ON / OFF`, `#btn-hover-guide`).
- Instrumented **every parameter, KPI card, studio preset, slate readout, telemetry inspector box, and action button** across Tabs 1–4 with `data-tip-title`, `data-tip-desc`, and `data-tip-affects`.
- Hovering over any control pops up an explanation of what the parameter does, its mathematical/protocol behavior, and color-coded green chips showing which subsystems and **Abu Ecosystem** components it affects (`Abu Track & Scan iOS`, `Windows Desktop Sync`, `UE5 LiveLinkAbuTrack`, `Omniverse USD`, `Hardware Appliance`, etc.).

### B. Native Model Context Protocol (MCP) Server & Global Antigravity Skill
- Implemented JSON-RPC 2.0 over `stdio` in [`apps/abu-clock-gui/src-tauri/src/mcp.rs`](../../apps/abu-clock-gui/src-tauri/src/mcp.rs) and standalone binary [`apps/abu-clock-gui/src-tauri/src/bin/abu_clock_mcp.rs`](../../apps/abu-clock-gui/src-tauri/src/bin/abu_clock_mcp.rs) (`abu-clock-mcp.exe` and `abu-clock.exe --mcp`).
- Exposed **7 structured MCP tools** for AI agents:
  1. `abu_clock_get_status`
  2. `abu_clock_configure`
  3. `abu_clock_synthesize_timecode`
  4. `abu_clock_schedule_capture`
  5. `abu_clock_pack_telemetry` (supports 29B FreeD, **37B `Abu Track & Scan` Extended FreeD**, OpenTrackIO JSON, and Enriched `AbuTrack` LiveLink JSON)
  6. `abu_clock_discover_nodes`
  7. `abu_clock_get_integration_guide` (`overview`, `ios_swift`, `python_pc`, `unreal_cpp`, `freed_37b`)
- Registered `abu-clock` globally in `C:\Users\USer\.gemini\config\mcp_config.json`, created the global skill `C:\Users\USer\.gemini\config\skills\abu-clock\SKILL.md`, and installed all 7 lazy MCP tool schema `.json` files in `C:\Users\USer\.gemini\antigravity\mcp\abu-clock\`.

### C. `Abu Track & Scan` Ecosystem Interoperability (`crates/abu-network` & `apps/abu-clock-gui`)
- **37-Byte `Abu Track & Scan` Extended FreeD (`crates/abu-network/src/telemetry/freed.rs`):** Added `FREED_ABUTRACK_37_LEN = 37`, `FreeDPacket::to_abutrack_37b_bytes()`, and `FreeDPacket::from_abutrack_37b_bytes()` (`0xD1` 29-byte FreeD + 8-byte big-endian `int64` ms timestamp) matching `UDPStreamingManager.swift`, `camtrack_desktop_gui.py`, and `LiveLinkAbuTrackSource.cpp`.
- **Stratum-1 SNTPv4 Responder & Auto-Discovery Beacon (`crates/abu-network/src/ecosystem.rs` & `server.rs`):**
  - Added `SntpResponder` answering 48-byte RFC 4330 SNTPv4 client requests (`0x1B`) from `NTPSyncClient.swift` on unprivileged UDP port `50320` (and HTTP `POST /api/sntp`).
  - Added `AbuEcosystemDiscoveryBeacon` (`"ABU_ECO_V1"`), `GET /api/ecosystem/discover`, and `POST /api/ecosystem/register` so iOS, Windows Desktop Sync, and UE5 nodes automatically find each other on the LAN without manual IP entry.
  - Added `AbuTrackLiveLinkPacket` extending `LiveLinkAbuTrackSource.cpp`'s JSON schema with `smpteTimecode`, `bcdTimecode`, `taiNs`, `subframePhase`, and `clockLockState`.
- **Comprehensive Documentation:**
  - Created [`docs/ABU_TRACK_AND_SCAN_INTEGRATION_GUIDE.md`](../ABU_TRACK_AND_SCAN_INTEGRATION_GUIDE.md) and [`docs/MCP_AND_API_GUIDE.md`](../MCP_AND_API_GUIDE.md).
