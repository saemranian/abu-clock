# Walkthrough — `P3-T4` (`v0.0.0.13`): Intuitive Vector-Icon Studio UI, Window Title Version, Live 8 Hz Servo & Official User/Developer Manuals

## Summary of Changes
1. **Audit & Backend Upgrades (`apps/abu-clock-gui/src-tauri/src/{lib.rs, server.rs, main.rs}`)**:
   - Bound a real `abu_network::TimestampedUdpSocket` (`127.0.0.1:50319`) inside `GuiAppController` and exposed live UDP socket TX/RX packet counters and departure TAI timestamps in `GuiSlateSnapshot`.
   - Added a background 8 Hz (`125 ms`) Kalman servo ticker thread in `server.rs` (toggleable from the UI via `8 Hz Auto-Sync Stream: ON/PAUSED`) so the 40-sample SVG Phase Oscilloscope and Kalman metrics update continuously in real time.
   - Added `POST /api/shutdown` and `shutdown_existing_instance()` in `main.rs` so launching a new `abu-clock.exe` cleanly replaces any previously running server on `127.0.0.1:7878`.
2. **UI/UX Redesign, Vector Icons & Window Title Bar Version (`ui_html.rs`, `index.html`, `App.tsx`)**:
   - Added the live version number (`Abu Clock v0.0.0.13 — Precision Master Clock, Timecode & Sync Studio`) directly to `<title>` and dynamic `document.title` (visible in the top white Windows title bar) along with a custom SVG clock/slate favicon.
   - Redesigned the 5-tab navigation bar as a single horizontal row with custom SVG icons and sub-labels.
   - Added **1-Click Studio Scenario Presets** (`Virtual Production 24 fps`, `Broadcast NTSC 29.97 DF`, `RoboSense/XGRIDS LiDAR 10 Hz gPTP`, `UE5 & Omniverse 60 fps`, `Mobile Wi-Fi Follower Rig`), grouped parameter sections, clipboard copy buttons, and toast notifications.

     1. *Interactive Visual Studio Tour* (annotated SVG map + 6 step cards with live "Try It Now" buttons)
     2. *Core Engineering Fundamentals & Diagrams* (SVG comparison of Naive UDP triggers vs. `SCHEDULE_CAPTURE_AT` barrier triggers and the Kalman PLL state machine)
     3. *Developer SDK & Engine Integration Guide* (C/C++17, Python/Omniverse, and HTTP REST API reference)
     4. *Studio Operator Checklist & Troubleshooting*
3. **Official User Manual & Developer Guide in Repository (`docs/`)**:
   - Created [`docs/USER_MANUAL.md`](../USER_MANUAL.md) and [`docs/DEVELOPER_GUIDE.md`](../DEVELOPER_GUIDE.md) and linked them from [`README.md`](../../README.md).
