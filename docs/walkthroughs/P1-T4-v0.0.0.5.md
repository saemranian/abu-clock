# Walkthrough: Task `P1-T4` — Dual-Mode Network Synchronization Engine (`PTPv2.1`, `gPTP`, & `AbuSync CSPTP`) (`v0.0.0.5`)

## Overview
Implemented the multi-profile network synchronization engine inside `/crates/abu-network/src/ptp/` supporting SMPTE ST 2059-2, IEEE 802.1AS (gPTP), AES67 Harmonized, and the unprivileged AbuSync CSPTP (`UDP 50319/50320` + mDNS `_abuclock._udp.local.`) profile.

## Completed Steps
1. **Step 1 — Branch & Concurrency Lock**:
   - Checked out `agent/antigravity/P1-T4-ptp-network` and acquired `WORKING` lock on `crates/abu-network/`.
2. **Step 2 — Four Timing Profiles (`src/ptp/profiles.rs`)**:
   - Implemented `TimingProfileConfig` for:
     - `SmpteSt2059_2` (Multicast `224.0.1.129`, UDP `319`/`320`, Default Domain `1`, `8 Hz` Sync).
     - `Ieee802_1AsGptp` (Multicast `224.0.0.107`, Peer-to-Peer delay, `8 Hz` Sync for RoboSense E1R LiDAR).
     - `Aes67Harmonized` (AES-R16-2016 harmonized parameters).
     - `AbuSyncCsptp` (Unprivileged UDP `50319`/`50320`, `16 Hz` Sync, Client-Server PTP, mDNS `_abuclock._udp.local.`).
3. **Step 3 — BMCA, Port State Machine, & Timestamped Socket (`src/ptp/engine.rs`)**:
   - Implemented `BmcaDataset`, `DualModePtpEngine`, `PtpWireMessage` 4-timestamp offset/delay calculation, and `TimestampedUdpSocket::bind_dual_mode()` with automatic unprivileged fallback.
4. **Step 4 — SMPTE ST 2059-2 Synchronization Metadata (SM) TLV (`src/ptp/smpte_tlv.rs`)**:
   - Implemented 20-byte big-endian wire serialization (`to_bytes` / `from_bytes`) for the SMPTE Organization Extension TLV (`0x000E9B`, subtype `0x000001`).
5. **Step 5 — Verification & Version Bump (`v0.0.0.5`)**:
   - Verified loopback exchange, BMCA election, and SM TLV wire round-trip (`cargo test --workspace`), bumped version to `v0.0.0.5`, merged to `dev`, and tagged `v0.0.0.5`.
